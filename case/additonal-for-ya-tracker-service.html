Сервис-дополнение к Яндекс Трекеру

У заказчика возникла необходимость управлять сущностями Яндекс Трекера, для которых отсутствовал интерфейс в стандартном веб-приложении. Доступ к необходимым операциям предоставлялся только через API.

Разработал отдельный веб-сервис на Laravel с собственным интерфейсом и интеграцией с API Яндекс Трекера. Реализовал необходимые операции, предусмотрел обработку ошибок и нестабильных ответов API.

В процессе разработки обнаружил ошибку на стороне API Яндекса: при определённом сценарии запрос приводил к ответу HTTP 500.

Сервис был введён в эксплуатацию и предоставил заказчику инструмент для выполнения операций, необходимых в его бизнес-процессах.
